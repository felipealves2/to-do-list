#- To-Do List

Uma aplicação web simples e responsiva para gerenciamento de tarefas, desenvolvida com HTML, CSS e JavaScript puro.

## 📋 Sobre o projeto

O To-Do List é uma lista de tarefas desenvolvida com o objetivo de praticar conceitos fundamentais de desenvolvimento web e manipulação do DOM com JavaScript.

A aplicação permite adicionar, concluir e remover tarefas de forma simples e intuitiva.

## 🚀 Funcionalidades

- [x] Adicionar tarefas
- [x] Remover tarefas
- [x] Contador de tarefas
- [x] Identificação de lista vazia
- [x] Interface responsiva


## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- DOM API
